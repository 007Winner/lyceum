The Lyceum

Make five minds reconsider.

Philosophical conversation game

The problem

Most dialogue games reward finding a hidden answer. Real inquiry rewards a defensible argument and intellectual revision.

The new idea

Persuasion is the mechanic. The philosopher's own Markdown prompt defines what counts as a reason.

Five agents + evaluator

Plato · Aristotle · Machiavelli · Hume · Kant

player → philosopher → evaluator → next room

How it feels

One room, one conversation, one map of minds. The interface stays quiet so the arguments stay loud.

Primary texts

Fourteen Gutenberg editions feed a local SQLite FTS5 index. Relevant passages ground each philosopher's reasoning while remaining reference material under the system rules.

Cost control

Two calls per turn, 420 output-token cap, 12-turn room limit, 120-request session ceiling.

Safety

Prompt-injection resistant prompts, independent evaluation, input validation, and an append-only audit trail.

Impact

A low-friction way for students and curious adults to practice disagreement without a grading rubric or “correct” keyword.
