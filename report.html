The Lyceum

A game where a player advances by giving five philosophers a real reason to reconsider.

What are the AI agents?

There are five philosopher agents: Plato (definitions and Forms), Aristotle (causes and practical wisdom), Machiavelli (power and consequences), Hume (experience and skepticism), and Kant (universal law and dignity). An impartial evaluator checks that a concession is substantive. Their editable behavior lives in prompts.md.

How the agents work

Each turn uses at most two model requests. The evaluator can authorize progression only when both the argument and the philosopher's explicit reconsideration support it.

Model and cost

The app uses Portkey with gpt-6-luna through PydanticAI. The harness caps responses at 420 output tokens. A typical turn is approximately 900 input tokens and 250 output tokens across two calls; measure exact usage from the budget_requests and budget_output_tokens fields in a live session. At an illustrative $0.20 per million input tokens and $0.80 per million output tokens, that is about $0.00038 per turn, $0.01 for a 25-turn playthrough, $1 per 100 users, and $100 per 10,000 users.   • Malformed, empty, and overlong messages are rejected by harness.py.
  • Input length, model output, and total session request budgets prevent runaway cost while each philosopher conversation remains open until persuasion.
  • Every turn writes a redacted event to output/audit.jsonl; message contents and keys are not persisted.

Walkthrough

  1. Create a session; Plato greets the player.
  2. Ask a question or provide a counterexample in the dialogue box.
  3. The philosopher replies in first person; the evaluator checks the concession.
  4. If earned, the map opens the next room. The same loop repeats for all five minds.

Primary-text grounding

The repository includes fourteen Project Gutenberg plain-text editions across the five philosophers, with bibliographic metadata in data/sources.json. A local SQLite FTS5 index retrieves up to three relevant passages only when a philosophical or historical topic makes grounding useful. The passages remain invisible reference material, are never instructions, are never quoted automatically, and are excluded from the independent evaluator. Retrieval events record the work, passage ID, and source URL in output/retrieval_log.jsonl. Project Gutenberg has no direct Metaphysics edition in this corpus build; that absence is documented and Aristotle's available Poetics is included as the substitute.

Validation run

With the configured Portkey key, the live gpt-6-luna model was exercised for all five philosophers across greetings, casual conversation, humor, daily-life questions, and justice. The 30-response acceptance transcript is saved in output/model_conversation_tests.json. A separate 13-turn live conversation passed without a turn-count error; its transcript is in output/open_conversation_test.json.
